# AI Clinic

Ambient intelligence for AI-assisted clinical workflows.

AI Clinic aims to help healthcare professionals capture clinical interactions,
prepare structured consultation documentation, identify follow-up actions, and
coordinate care while keeping clinicians in control.

## Repository structure

- `backend/` — API, agents, orchestration, services, integrations, and tests.
- `frontend/` — user interface components and consultation workflows.
- `data/` — raw, processed, synthetic, and sample data.
- `docs/` — architecture, research, data, agent, integration, and development
  documentation.
- `infrastructure/` — Docker assets, scripts, and monitoring configuration.

Clinical documentation generated by the system is intended for clinician
review and approval.
